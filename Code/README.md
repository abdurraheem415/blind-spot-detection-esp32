# Source Code

This folder contains the Arduino source code for the **Blind Spot Detection & Driver Warning System using ESP32**.

## Technologies Used

- ESP32 Development Board
- Arduino IDE
- Embedded C++
- HC-SR04 Ultrasonic Sensors
- LEDs
- Active Buzzers

## Main File

- `blind_spot_detection.ino`

## Note

> **Disclaimer:** The original Arduino source file developed during the Engineering Clinic project was unavailable. The `blind_spot_detection.ino` file in this repository is a reconstructed implementation based on the documented project design, hardware configuration, and working principle. It is intended to demonstrate the project's functionality and system architecture.
